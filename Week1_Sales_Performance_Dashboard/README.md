# Week 1 – Sales Performance Dashboard

## Objective
Analyse sales data to identify revenue trends, top-selling products and
regional performance, and present the findings in an Excel dashboard.

## Dataset
Sample retail sales dataset (40 orders, Jul–Sep 2026) with intentional
data-quality issues: duplicates, blanks, mixed date formats, inconsistent
text and text stored in numeric columns.

## What I did
1. Data cleaning – removed duplicates, standardised dates/text, fixed
   numeric columns and handled blanks (documented in the Cleaning Log sheet).
2. Descriptive statistics – mean, median, mode, std deviation, quartiles.
3. KPIs – total revenue, average order value, units sold, cancellation rate.
4. Dashboard – monthly revenue trend, top products, regional performance,
   with interactive Region and Category filters.

## File
Week1_Data_Analytics_Task.xlsx
- Dashboard – KPIs, charts and filters
- Lifecycle, Raw Data, Cleaning Log, Clean Data
- Descriptive Stats, KPI Report, Analyst Roles

## Key findings
- Total revenue (excl. cancelled): ₹19.1 lakh from 30 valid orders
- Top product: Laptop | Top region: West | Top category: Electronics
- 25% of orders were cancelled
