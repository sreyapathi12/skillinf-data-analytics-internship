# Survey questions

Employee engagement survey, run in 3 rounds (Jan, Apr, Jul 2026). The data is **sample data** made by `scripts/generate_sample_survey.py`.

| # | Question | Answer type |
|---|----------|-------------|
| Q1 | Overall, how satisfied are you working here? | Rating 1-5 |
| Q2 | How satisfied are you with your work-life balance? | Rating 1-5 |
| Q3 | My manager supports me. | Rating 1-5 |
| Q4 | I see a path to grow my career here. | Rating 1-5 |
| Q5 | My pay is fair for the work I do. | Rating 1-5 |
| Q6 | How likely are you to recommend us as a place to work? | Score 0-10 (used for NPS) |
| Q7 | How manageable is your workload? | One choice (4 options) |
| Q8 | Do you plan to stay for the next 12 months? | One choice (Yes / Not sure / No) |
| Q9 | Which benefits do you value most? | Up to 3 choices |
| Q10 | Any other comments? | Open text |

Also collected: department, location, age, tenure, survey round.
